# QA audits

Reports and evidence from the IFT Tech QA team, for the Logos and Status projects.

| Folder | What is in it |
| --- | --- |
| [`reports/`](reports/) | Full QA reports, one Markdown file per report. The GitHub issue for a report is short and links here. |
| [`evidence/`](evidence/) | Logs, scripts, screenshots and recordings for each issue and test run. |
| [`templates/`](templates/) | Templates for a report, its GitHub issue and a run folder `README.md`. |
| [`tools/`](tools/) | Scripts, for example the script that bundles a report and its evidence into one zip file. |

Each folder has a `README.md` with its own path rules.

For [Status evidence](evidence/status/), a second run on the same day and platform uses a name like `2026-11-25-android-pixel8-2`.
