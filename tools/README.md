# Tools

| Script | What it does |
| --- | --- |
| [`make-report-bundle.sh`](make-report-bundle.sh) | Builds one zip from a tag: the report, every evidence folder it links, its own files folder and `SHA256SUMS`. See [`reports/README.md`](../reports/README.md#send-a-report-with-its-evidence). |

The scripts work on macOS and Linux.
